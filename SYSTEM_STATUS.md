## 🛠️ Troubleshooting

### Backend won't start on port 8081
- Check if port is in use: `netstat -ano | findstr 8081`
- Kill process: `taskkill /PID [PID] /F`

### Database connection failed
- Verify MySQL is running: `netstat -ano | findstr 3306`
- Check credentials: username=root, password=root123
- Database: neurofleetx (auto-created)

### Frontend can't reach backend
- Check backend is running on port 8081
- Verify config in `neurofleetx-frontend/src/config/config.js`
- Clear browser cache and refresh (Ctrl+Shift+Delete)

### CORS errors
- Backend CORS is configured in `SecurityConfig.java`
- Frontend origin (http://localhost:5174) is allowed
